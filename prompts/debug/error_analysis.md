## 常见错误速查

### 编译错误
| 错误 | 原因 | 解决 |
|-----|------|-----|
| undefined reference | 链接缺失 | 添加库链接 |
| no matching function | 参数不匹配 | 检查函数签名 |
| incomplete type | 前向声明不够 | 包含完整头文件 |

### 运行时错误
| 错误 | 原因 | 解决 |
|-----|------|-----|
| Segmentation fault | 非法内存访问 | 检查指针 |
| bad_alloc | 内存不足 | 检查内存使用 |
| out_of_range | 越界访问 | 检查索引 |

## 安全边界

⚠️ **注意事项**：
- 错误信息可能包含敏感路径或数据，注意脱敏
- 不要仅仅抑制错误，要找到根本原因
- 修复后验证不影响其他功能
