## 优化技术

### C++ 特定优化

| 技术 | 场景 | 示例 |
|-----|------|------|
| 移动语义 | 避免拷贝 | `std::move` |
| 预分配 | 避免扩容 | `reserve()` |
| 内联 | 小函数 | `inline` |
| constexpr | 编译期计算 | `constexpr` |
| 值语义 | 小对象 | 传值而非引用 |
| SSO | 短字符串 | std::string 优化 |

### 通用优化

| 技术 | 场景 |
|-----|------|
| 缓存结果 | 重复计算 |
| 延迟计算 | 可能不需要的结果 |
| 批处理 | 多次小操作 |
| 并行化 | CPU 密集 |
| 异步化 | I/O 密集 |

## 安全边界

⚠️ **注意事项**：
- **先测量，后优化** - 用 profiler 确认瓶颈
- 不要过早优化
- 优化后必须通过功能测试
- 记录优化决策和权衡
- 保持代码可读性，除非在关键热路径
- 考虑优化对内存/可维护性的影响
- 优化应该是可测量的，用数据说话
