## 算法优化技术

### 常见优化方向

| 从 | 到 | 技术 |
|---|---|------|
| O(n²) | O(n log n) | 排序后二分、分治 |
| O(n²) | O(n) | 双指针、滑动窗口、哈希表 |
| O(n) | O(log n) | 二分查找 |
| O(n) | O(1) | 数学公式、位运算 |

### 优化策略

1. **减少重复计算**
   - 记忆化（Memoization）
   - 动态规划
   - 预计算

2. **改变数据结构**
   - 数组 → 哈希表（O(n) → O(1) 查找）
   - 数组 → 堆（O(n) → O(log n) 取最值）
   - 链表 → 数组（提高缓存命中）

3. **算法替换**
   - 暴力 → 分治
   - 递归 → 迭代
   - 线性搜索 → 二分搜索

4. **减少操作次数**
   - 提前终止
   - 剪枝
   - 合并操作
