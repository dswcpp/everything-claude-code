## 优化技术

### C++ 内存优化

| 技术 | 场景 | 示例 |
|-----|------|------|
| 对象池 | 频繁创建销毁 | 预分配+复用 |
| 小对象优化 | 小数据 | SSO、SBO |
| 预分配 | 已知大小 | `vector::reserve` |
| 移动语义 | 避免拷贝 | `std::move` |
| string_view | 只读字符串 | 避免拷贝 |
| 紧凑布局 | 减少 padding | 成员排序 |
| 位域 | 标志位 | 减少存储 |

### 数据结构选择

| 需求 | 推荐结构 |
|-----|---------|
| 连续访问 | `vector` |
| 频繁插入删除 | `list` / `deque` |
| 快速查找 | `unordered_map` |
| 有序 + 查找 | `map` / `set` |
| 稀疏数据 | 压缩存储 |

## 安全边界

⚠️ **注意事项**：
- 内存优化可能影响性能（时空权衡）
- 对象池需要考虑线程安全
- 缓存淘汰策略要合理
- 不要过度优化导致代码复杂
- 优化后验证功能正确性
