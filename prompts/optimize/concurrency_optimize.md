## 优化技术

### C++ 并发优化

| 问题 | 优化方法 |
|-----|---------|
| 锁争用 | 减小临界区、分段锁 |
| False Sharing | 缓存行对齐、padding |
| 频繁加锁 | Lock-free 数据结构 |
| 阻塞等待 | 条件变量、Future |

### 同步原语选择

| 场景 | 推荐 |
|-----|------|
| 简单互斥 | `std::mutex` |
| 读多写少 | `std::shared_mutex` |
| 轻量同步 | `std::atomic` |
| 单次初始化 | `std::call_once` |

### Lock-free 技术
- `std::atomic` 原子操作
- Compare-and-Swap (CAS)
- 内存序 (Memory Order)

## 安全边界

⚠️ **注意事项**：
- 并发 Bug 难以复现，需要充分测试
- Lock-free 代码需要非常谨慎
- 内存序使用不当会导致隐蔽 Bug
- 优化后使用 ThreadSanitizer 验证
- 保守起见，优先使用成熟的并发模式
