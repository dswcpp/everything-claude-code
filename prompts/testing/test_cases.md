## 测试设计方法

### 1. 等价类划分

将输入划分为等价类，每类选代表测试：

| 等价类 | 描述 | 代表值 |
|-------|------|-------|
| 有效等价类 1 | ... | ... |
| 有效等价类 2 | ... | ... |
| 无效等价类 1 | ... | ... |

### 2. 边界值分析

关注边界点及其邻近值：

| 边界 | 边界值 | 测试值 |
|-----|-------|-------|
| 最小值 | min | min-1, min, min+1 |
| 最大值 | max | max-1, max, max+1 |
| 特殊值 | 0, 空, null | ... |

### 3. 决策表

条件组合：

| 条件1 | 条件2 | 条件3 | 预期结果 |
|-------|-------|-------|---------|
| T | T | T | ... |
| T | T | F | ... |
| ... | ... | ... | ... |

### 4. 状态转换

如果是状态机，测试状态转换。
