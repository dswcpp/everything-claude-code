## 多文件审查要点

### 1. 变更一致性
- [ ] 所有相关文件是否都已修改
- [ ] 接口变更是否同步更新调用方
- [ ] 头文件和源文件是否匹配

### 2. 依赖关系
- [ ] 是否引入循环依赖
- [ ] 依赖方向是否正确（高层依赖低层）
- [ ] 是否有隐式依赖

### 3. 跨文件一致性
- [ ] 命名风格是否一致
- [ ] 错误处理方式是否一致
- [ ] 日志格式是否一致

### 4. 接口设计
- [ ] 公共接口是否稳定
- [ ] 是否破坏现有 API
- [ ] 是否需要版本兼容

### 5. 测试覆盖
- [ ] 新增代码是否有测试
- [ ] 跨模块交互是否有集成测试
- [ ] 现有测试是否需要更新

## 安全边界

⚠️ **注意事项**：
- 确保所有必要的文件都包含在审查中
