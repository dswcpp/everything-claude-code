## 内存安全审查清单

### 1. 智能指针使用
- [ ] 是否优先使用 `std::unique_ptr` / `std::shared_ptr`
- [ ] `std::make_unique` / `std::make_shared` 而非 `new`
- [ ] 避免裸指针持有所有权
- [ ] `std::weak_ptr` 打破循环引用

### 2. 资源管理（RAII）
- [ ] 所有资源是否通过 RAII 管理
- [ ] 构造函数异常安全
- [ ] 析构函数不抛异常
- [ ] 拷贝/移动语义是否正确

### 3. 常见内存问题
- [ ] **Use-after-free**：访问已释放的内存
- [ ] **Double-free**：重复释放
- [ ] **内存泄漏**：忘记释放或异常路径泄漏
- [ ] **悬空指针**：指向已销毁对象
- [ ] **野指针**：未初始化的指针

### 4. 缓冲区安全
- [ ] 数组边界检查
- [ ] 使用安全的字符串函数（`strncpy`、`snprintf`）
- [ ] 优先使用 `std::string`、`std::vector`
- [ ] 避免 VLA（变长数组）

### 5. 整数安全
- [ ] 整数溢出检查
- [ ] 有符号/无符号混用
- [ ] 类型转换截断
- [ ] size_t 与有符号整数比较

### 6. 多线程内存安全
- [ ] 共享数据是否正确同步
- [ ] 避免数据竞争
- [ ] 原子操作是否正确使用
- [ ] 线程局部存储使用

## 推荐替换

| 不安全写法 | 安全替代 |
|-----------|---------|
| `char*` 持有所有权 | `std::string` |
| `T*` 持有所有权 | `std::unique_ptr<T>` |
| `new T` | `std::make_unique<T>()` |
| `malloc/free` | 智能指针或容器 |
| `strcpy` | `strncpy` 或 `std::string` |
| `sprintf` | `snprintf` 或 `std::format` |
| `memcpy` 无长度检查 | 带边界检查的版本 |

## 安全边界

⚠️ **注意事项**：
- 本审查基于静态分析，建议配合 Valgrind/ASan 动态检测
- 修改内存管理代码需要充分测试

- 旧代码改造应渐进式进行，避免引入新 Bug
