## 安全审查清单

### 1. 输入验证
- [ ] 所有外部输入是否经过验证
- [ ] 输入长度/范围是否有限制
- [ ] 特殊字符是否正确转义
- [ ] 文件路径是否防止目录遍历攻击

### 2. 注入攻击
- [ ] SQL 注入：是否使用参数化查询
- [ ] 命令注入：是否过滤 shell 命令
- [ ] XSS：HTML/JS 是否转义
- [ ] LDAP/XML 注入

### 3. 内存安全（C/C++）
- [ ] 缓冲区溢出：strcpy → strncpy
- [ ] 格式化字符串：printf(user_input) → printf("%s", user_input)
- [ ] 整数溢出：算术运算前是否检查
- [ ] Use-after-free：指针释放后是否置空
- [ ] Double-free：是否重复释放

### 4. 认证与授权
- [ ] 密码是否明文存储（应使用哈希+盐）
- [ ] 会话管理是否安全
- [ ] 权限检查是否完整
- [ ] 敏感操作是否有二次验证

### 5. 敏感数据处理
- [ ] 密钥/密码是否硬编码
- [ ] 日志是否泄露敏感信息
- [ ] 错误消息是否泄露内部信息
- [ ] 敏感内存使用后是否清零

### 6. 并发安全
- [ ] 竞态条件（TOCTOU）
- [ ] 死锁风险
- [ ] 共享资源是否正确加锁

### 7. 加密安全
- [ ] 是否使用过时算法（MD5、SHA1、DES）
- [ ] 随机数是否使用安全来源
- [ ] 证书验证是否正确

## 安全边界

⚠️ **注意事项**：
- 本审查仅覆盖静态代码分析，不能替代渗透测试
- 业务逻辑漏洞需要结合上下文理解
- 建议敏感代码由安全团队进行专门审计
- 任何安全修复都应通过完整的回归测试
