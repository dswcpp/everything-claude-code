## 常见错误速查

### C++ 编译错误

| 错误 | 含义 | 常见原因 |
|-----|------|---------|
| undefined reference | 符号未定义 | 忘记链接库 |
| no matching function | 无匹配函数 | 参数类型不匹配 |
| incomplete type | 不完整类型 | 只有前向声明 |
| ambiguous call | 调用不明确 | 多个重载匹配 |

### C++ 运行时错误

| 错误 | 含义 | 常见原因 |
|-----|------|---------|
| Segmentation fault | 段错误 | 访问非法内存 |
| bad_alloc | 内存分配失败 | 内存不足 |
| pure virtual call | 纯虚函数调用 | 构造/析构中调用 |
