## 解释要求

### 1. 概述
- 代码的整体功能是什么
- 在系统中的作用

### 2. 逐段解释

对代码的主要部分进行解释：

```{{language}}
// 原代码片段
```
**解释**：这段代码做了什么，为什么这样做。

### 3. 数据流

描述数据如何在代码中流动：
```
输入 → 处理步骤1 → 处理步骤2 → 输出
```

### 4. 关键技术点

| 技术点 | 说明 | 为什么使用 |
|-------|------|----------|
| ... | ... | ... |

### 5. 潜在问题（如有）

---

## 解释深度

根据代码复杂度调整：

- **简单代码**：简要说明功能
- **复杂算法**：详细解释每一步
- **设计模式**：说明模式及其好处
- **性能优化**：解释优化技巧

---

## 安全边界

⚠️ **注意事项**：
- 解释应帮助理解，不是复述代码
- 指出隐含的假设和前提条件
- 说明边界情况的处理
- 如有安全相关代码，特别说明
