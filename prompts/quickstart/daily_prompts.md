```

```

### 完整重构流程

## 使用技巧

1. **选中代码后使用** - 大多数提示词需要配合选中的代码使用
2. **补充上下文** - 可以在提示词后补充更多背景信息
3. **组合使用** - 可以将多个简单提示词组合成复杂任务
4. **迭代优化** - 如果结果不满意，可以追加要求进一步优化
