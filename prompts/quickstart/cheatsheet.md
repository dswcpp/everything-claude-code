# 提示词速查卡

## 一句话提示词

| 场景 | 提示词 |
|-----|--------|
| 看不懂代码 | `解释这段代码` |
| 发现 bug | `找出这段代码的 bug` |
| 修复 bug | `修复这个 bug` |
| 代码太乱 | `重构这段代码` |
| 代码太长 | `拆分成多个函数` |
| 需要注释 | `添加注释` |
| 需要测试 | `生成单元测试` |
| 性能差 | `优化性能` |
| 不够安全 | `检查安全问题` |
| 内存问题 | `检查内存泄漏` |

---

## 快速模板

### 代码审查
```
审查这段代码，检查：bug、性能、安全、可读性
```

### Bug 修复
```
问题：[描述问题]
预期：[预期行为]
实际：[实际行为]
请修复
```

### 代码生成
```
实现一个函数：[功能描述]
输入：[参数]
输出：[返回值]
```

### 重构请求
```
重构这段代码，目标：[提高可读性/降低复杂度/消除重复]
```

---

## 后缀修饰词

在任意提示词后添加：

| 修饰词 | 作用 |
|-------|------|
| `...并解释` | 附带解释 |
| `...保持简洁` | 减少废话 |
| `...用 C++17` | 指定版本 |
| `...符合 Qt 风格` | 指定规范 |
| `...步骤详细` | 更详细 |
| `...只给代码` | 只要代码 |

## 追问模板

| 场景 | 追问 |
|-----|------|
| 不够详细 | `请详细解释一下 X 部分` |
| 需要替代方案 | `还有其他方案吗？` |
| 需要对比 | `和 Y 方案相比呢？` |
| 需要代码 | `给出完整代码` |
| 需要测试 | `写个测试验证一下` |
| 需要示例 | `给个使用示例` |
